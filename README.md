# Student Grade Calculator

A console-based Java application that calculates a student's average marks and assigns a grade based on their performance.

## Features

- Accepts the student's name.
- Takes marks for five subjects.
- Calculates the average marks.
- Assigns a grade based on the average.
- Displays the student's result as Pass or Fail.
- Validates marks to ensure they are between 0 and 100.
- Handles non-integer input.

## Grading Criteria

| Average Marks | Grade |
|---|---|
| 90–100 | A |
| 75–89.99 | B |
| 60–74.99 | C |
| 40–59.99 | D |
| Below 40 | F |

A student with an average of 40 or above passes; otherwise, the result is Fail.

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure a compatible JDK.
4. Open `StudentGradeCalculator.java`.
5. Run the `main()` method.
6. Enter the student's name and marks for five subjects.
